# โครงการเกมการศึกษา 3D RPG ป.5 (เทคโนโลยีเพื่อชีวิตประจำวัน)

เกมการศึกษาแนว 3D RPG สำหรับนักเรียนชั้นประถมศึกษาปีที่ 5 ครอบคลุมหลักสูตร 40 ด่าน (แบ่งเป็น 2 เทอม เทอมละ 20 ด่าน) พร้อมระบบบอสประจำทุกด่าน และระบบเลือกตัวละครชาย/หญิง

## โครงสร้างโปรเจกต์
- `game_data.json`: ฐานข้อมูล 40 ด่าน ชื่อบอส และภารกิจ
- `main.py`: โค้ดลอจิก Python สำหรับระบบเกมและการต่อสู้

## วิธีการรันโปรเจกต์บนเครื่องของคุณ
1. ติดตั้ง Python (เวอร์ชัน 3.x ขึ้นไป)
2. เปิด Terminal หรือ Command Prompt ในโฟลเดอร์โปรเจกต์
3. รันคำสั่ง:
   ```bash
   python main.py
   ```

## วิธีการนำขึ้น GitHub Pages
1. สร้าง Repository ใหม่บน GitHub (ตั้งค่าเป็น Public)
2. อัปโหลดไฟล์โปรเจกต์ทั้งหมดขึ้นไป
3. ไปที่ Settings > Pages เลือก Branch เป็น `main` และโฟลเดอร์เป็น `/ (root)` แล้วกด Save
4. คัดลอกลิงก์เว็บไซต์ไปเปิดให้นักเรียนเล่นได้ทันที!
